      Install LibreOffice to convert Word/Excel

      Converte Fácil uses LibreOffice on this computer for documents. It is free, and is not included in the Converte Fácil installer.

      1. Download LibreOffice from the official website.
      2. Run the installer (you may need an administrator password).
      3. Come back here and click Check again.

      Advanced: winget install TheDocumentFoundation.LibreOffice
