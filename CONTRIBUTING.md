# Contributing

Repo docs, code, issues, and PRs are written in **English**.  
The **app UI** must support English and Portuguese (i18n).

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Issues

**One issue per PR.** Branch naming:

```
fix/123-short-description
feat/45-short-description
```

## Suggested labels

- `type:feat` / `type:fix` / `type:docs` / `type:chore`
- `area:ui` / `area:imagemagick` / `area:pdf` / `area:installer` / `area:i18n` / `area:docs`
- `priority:high` / `priority:medium` / `priority:low`
- `good-first-issue`

## Flow

1. Pick an issue from the current milestone
2. Branch from `main`
3. Open a PR referencing the issue (`Fixes #N`)
4. Review / merge
