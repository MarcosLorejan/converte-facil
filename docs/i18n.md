# Adding UI strings (i18n)

Product UI supports **English (`en`)** and **Portuguese (`pt-BR`)**.

## Add a new string

1. Add the key to `src/i18n/en.json` with the English text.
2. Add the **same key** to `src/i18n/pt-BR.json` with the Portuguese text.
3. In HTML, mark the element:

```html
<p data-i18n="yourKey">English fallback</p>
```

4. TypeScript keys are inferred from `en.json` (`MessageKey`). If TypeScript complains, restart the TS server after editing JSON.

## Language preference

`src/i18n/index.ts` persists the choice in `localStorage` under `converte-facil.locale`.

## Do not

- Hard-code user-visible sentences in `.ts` / `.css` / Rust for the UI (prefer locale files).
- Mix languages in a single locale file.
